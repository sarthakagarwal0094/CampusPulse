# 🎓 CampusPulse

### Campus Event Management System

CampusPulse is a centralized web platform designed to simplify the complete campus event experience for **Administrators, Event Coordinators, and Participants**.

It brings event discovery, registration, participant management, attendance, and certificate access together in one platform.

---

## 📌 Problem Statement

Campus event activities are often scattered across different platforms.

Before an event, students may receive information through:

* WhatsApp groups
* Emails
* Posters
* Friends and peers

During an event, coordinators need to separately manage registrations, participant lists, attendance, and event records.

After an event, participants may have to search through emails, messages, or Google Drive links to find their certificates.

**CampusPulse aims to connect this fragmented journey through one centralized platform.**

---

## 💡 Proposed Solution

CampusPulse provides a unified interface for managing the complete campus event lifecycle.

```text
Discover Event
      ↓
Register
      ↓
Add to Calendar
      ↓
Participate
      ↓
Attendance
      ↓
Certificate
```

---

## 👥 User Roles

### 🛡️ Administrator

The Administrator manages overall event activities.

**Key Functions:**

* Dashboard overview
* Manage events
* View participants
* Monitor registrations
* View event statistics

### 👨‍💼 Event Coordinator

The Event Coordinator manages assigned events and their participants.

**Key Functions:**

* View assigned events
* Manage event details
* View participant lists
* Search and filter participants
* Manage attendance

### 🎓 Participant

Participants can discover and participate in campus events.

**Key Functions:**

* Discover events
* View event details
* Register for events
* Add registered events to Google Calendar
* Track registrations
* Access certificates
